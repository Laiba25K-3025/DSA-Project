# Hostel Management System

A console-based Hostel Management System developed in C++.

## Features

### 1. Warden Portal

- Add and manage student records.
- Allocate rooms.
- Manage payments and complaints.

### 2. Student Portal

- View personal details.
- Check payment information.
- Submit complaints and leave requests.

### 3. Security Guard Portal

- Record student entry and exit.
- Manage visitor records.

## Technologies Used

- C++
- Dev-C++
- MinGW Compiler

## How to Run in Dev-C++

1. Open Dev-C++.
2. Open the `.cpp` source file.
3. Select Execute → Compile & Run.
